# Agent Workflows

The Sovereign AI Workbench includes a bounded, multi-step Agent capable of orchestrating complex industrial tasks across multiple tools without requiring external cloud access.

## Capabilities

The Agent is accessed via the TUI's Agent tab and is designed to execute tasks like:
- *"Identify anomalous vibrations in the dataset, search the manual for a diagnosis, and create a chart and report."*

The Agent acts autonomously within a strict loop (Plan → Act → Observe → Decide), utilizing the configured local reasoning model (e.g., `qwen3:8b`).

## Allowed Tools

To prevent unbounded execution, the Agent only has access to a statically registered list of backend-authoritative tools:
- `list_data_sources`: Discovers available CSV/XLSX datasets.
- `data_analysis`: Performs deterministic numerical calculations on datasets.
- `knowledge_search`: Queries the local RAG vector store for operational knowledge.
- `create_chart`: Generates visual PNG charts (bar, line, scatter) using Matplotlib.
- `create_spreadsheet`: Generates structured Excel (`.xlsx`) workbooks.
- `create_document`: Generates formal Markdown or Word (`.docx`) reports.

## Safety and Visibility

- **Activity Trace:** The TUI visually renders the sequence of tools the Agent selected (e.g., `✓ Operational data analyzed`, `✓ Local knowledge searched`).
- **No Hidden Reasoning:** The raw internal "chain-of-thought" generated by the local LLM is intentionally suppressed. This prevents hallucinatory reasoning from being presented as fact.
- **Source Propagation:** If the Agent uses `knowledge_search`, the exact source document IDs are propagated to the final output. The TUI displays these in the **SOURCES** section, allowing the user to verify the provenance of the Agent's claims.
- **Artifact Auto-Save:** Any deliverables (charts, spreadsheets, documents) generated during the workflow are automatically registered by the backend, downloaded to the local workspace `outputs/` directory, and linked in the Agent's **SAVED ARTIFACTS** section.
